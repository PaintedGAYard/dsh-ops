# dev-diary

本目录是本项目的**决策与认知**记录，不是过程日志。

## 记什么

- **目标**：已冻结的目标，以及它为什么是这个。
- **决定**：某条路线为什么被选、被谁否定、否定理由。
- **认知修订**：我们曾经怎么理解，现在怎么理解，**是什么证据把它推翻的**。
- **主张表**（`claims-register.md`）：仓库文档 / 代码注释 / 测试里写着、但需要验证的断言。
- **开放问题**：还没答案、且会改变下一步做法的问题。

## 不记什么

- 试错细节、被否决的中间尝试、逐次读数 —— 这些只留结论。
- 命令输出原文 —— 放 `submissions/04-EVIDENCE.md` 或探针目录，这里只放指针。
- 任何会过期且不影响决策的东西。
